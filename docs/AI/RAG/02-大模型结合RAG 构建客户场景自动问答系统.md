## ✂️ 将问题文本进行切割

**Text Segmentation & QA Extraction**

1. 📄 **文本过长切割**：将原始文本分割为语义片段（chunk），提升检索精度。
2. ❓ **抽取问答对**：从长文本中提取 QA 对，将问题（Q）向量化用于语义检索。

📌 **数据处理三步法**：

1. 🔍 规则匹配
2. 🤖 利用 LLM 抽取
3. 👨‍💻 人工处理


## 🎯 优化回答

为了让大模型更适应客户场景，我们采用：

- 📚 **继续预训练（Continued Pretraining）**
- 🛠 **SFT 微调（Supervised Fine-tuning）**

✅ 进一步提升了回答的准确性与上下文匹配度。

------

## 🔄 Re-rank 重排序

大模型的回复精度，很大程度取决于 **召回文本的相关性**。

- ⚡ **向量检索**：高效，但每条向量独立计算，相关性有限。
- 🔧 **引入 Re-rank 模型**：基于 **BERT 结构**，输入为问题 + 文本，输出为相似度分数。
- 📊 **处理流程**：对召回的 *n 个 context* 排序，将相关性最高的结果传递给大模型。

------

## 📈 效果提升

在开发过程中，我们采用 **人工评估** 测试各方法在测试集上的精度提升。

结果表明：

- 🎯 Re-rank + 微调模型 → 显著提升回答准确率
- 🏆 系统在客户场景下的表现更可靠
