## 1、OpenClaw 到底是个啥？

官网：https://openclaw.ai/

文档：https://docs.openclaw.ai/zh-CN

先搞清楚我们要装的是什么东西。

OpenClaw 是一个开源的 AI 代理平台，核心能力就一句话：用自然语言驱动工具完成任务。

![image-20260227235001194](.\image\image-20260227235001194.png)

它不是那种只会回答问题的聊天机器人，而是真正能动手的 Agent。

读写文件、执行命令、操控浏览器、处理邮件，这些它都能干。

更重要的是，它支持通过飞书、钉钉、企业微信、QQ 这些 IM 工具来控制。

![image-20260227235246576](.\image\image-20260227235246576.png)

你在飞书里说帮我整理一下今天的待办事项，它就会乖乖去执行。

OpenClaw 本身不具备独立的大语言模型推理能力，需要对接大模型才能听懂指令。

支持的大模型很多，阿里云百炼、智谱 GLM、OpenAI、Anthropic 都可以。



## 2、**前置环境准备**

开始之前，先把该装的装好，免得中途报错一脸懵逼。

### **Node.js 升级到 22 以上**

这是硬性要求，低于 22 版本会报错。

Windows用户可以直接使用nvm 插件切换node版本

![image-20260228000804455](.\image\image-20260228000804455.png)

装完后验证一下：

```
node -v
```

### **准备大模型的 API Key**

1. 智谱
2. miniMax （新用户免费15块钱额度）
3. 百炼

## **3、安装 OpenClaw**

### **手动安装**

如果一键脚本有问题，也可以手动安装：

```
npm install -g @openclaw/cli
```

### **启动配置向导**

安装完成后，执行配置向导：

```
openclaw onboard
```

这个命令会引导你完成核心配置。

## **4、启动 OpenClaw 服务**

配置完成后，启动核心服务：

```
openclaw gateway start
```

这个命令会启动 OpenClaw 的网关服务，默认监听 18789 端口。

检查服务状态：

```
openclaw gateway status
```

如果显示 `running`，说明服务正常启动。

![image-20260228001105587](.\image\image-20260228001105587.png)

### **验证安装成功**

浏览器访问 `http://127.0.0.1:18789/`，如果能打开 OpenClaw 的 Web 控制面板，说明本地部署成功了。

![image-20260228001657468](.\image\image-20260228001657468.png)

## 5、创建飞书应用

> 推荐使用Whatapps 一键就可以注册OpenClaw

当然了，如果你不想在启动的时候配置飞书，也可以在 OpenClaw 安装成功后接入飞书。

### **第一步：进入飞书开放平台**

访问飞书开放平台，用飞书账号登录。点击创建企业自建应用，填写应用名称和描述。应用类型选企业自建应用就行。

### **第二步：获取凭证**

应用创建成功后，在凭证与基础信息页面，你能看到：

- **App ID**：应用的唯一标识
- **App Secret**：应用的密钥

把这两个值复制保存好，后面配置要用（前面演示过了）。

### **第三步：添加机器人能力**

在应用的应用功能页面，点击添加应用能力，选择机器人。开通后，这个应用就能以机器人的身份出现在飞书群里了。

### **第四步：配置权限**

在权限管理页面，开通以下权限：

- `im:message`：获取与发送单聊、群聊消息
- `im:message:send_as_bot`：以应用身份发消息
- `im:chat`：获取群组信息
- `im:chat:readonly`：读取群组信息

这些权限是 OpenClaw 接收和发送消息的基础。或者直接选择批量导入按钮，把 OpenClaw 官方推荐的权限全部接入进去。

![image-20260301225009393](.\image\image-20260301225009393.png)

### **第五步：配置事件订阅**

在事件订阅页面，开启事件订阅。

![image-20260301225018027](.\image\image-20260301225018027.png)

直接选择长链接，当你的 OpenClaw 启动后，这里就可以保存成功。

添加事件 `im.message.receive_v1`：接收消息

这样当有人在飞书群里@机器人时，飞书会把消息推送到 OpenClaw。

### **第六步：发布应用**

配置完成后，在版本管理与发布页面，创建一个版本并提交审核。

![image-20260301225036065](.\image\image-20260301225036065.png)

审核通过后（免审，比腾讯的 QQ 和企业微信方便），应用就可以在企业内使用了。

![image-20260301225047001](.\image\image-20260301225047001.png)

## 6、在Open Claw中配置飞书通道

在飞书里打开应用，然后@它发一条消息：

> 你好。

![image-20260301225144801](.\image\image-20260301225144801.png)

首次会提示你要配对，直接把这条消息发送到 OpenClaw 聊天窗口。

![image-20260301225209572](.\image\image-20260301225209572.png)

配对完成后，再回到飞书这里，随便发送一条信息，就完成通信了。![image-20260301225221517](.\image\image-20260301225221517.png)
